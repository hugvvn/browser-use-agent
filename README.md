# Browser-use Agent with Skills Routing

## 项目介绍
基于 browser-use 构建浏览器自动化 Agent，并增加 Weather / GitHub Skills 提升查询准确性。

## 功能
- 浏览器自动化（browser-use）
- 天气查询（OpenWeather API）
- GitHub 仓库信息查询

## 技术栈
Python / browser-use / Playwright / Qwen API / requests

## 运行方式
```bash
pip install -r requirements.txt
python main.py
